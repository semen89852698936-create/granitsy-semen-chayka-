# Перенос курса на площадку, доступную пользователям России

> **Внимание:** проект подготовлен, но ещё НЕ развёрнут в России. Адреса `*.vercel.app` остаются на Vercel. Смену публичной ссылки и подключение Prodamus делайте только после успешного развёртывания и проверки из российских сетей.

## Цель

Сохранить все 30 учебных ситуаций, задания, 3-раундовые ИИ-тренировки, бессрочный платный доступ за 399 ₽ и 30 диалогов на покупку. Разместить **и HTML, и API, и базу покупателей** на хостинге, до которого можно достучаться из РФ без VPN.

Из-за сетевых ограничений для некоторых российских провайдеров `vercel.app` может быть недоступен. Создание короткого `vercel.app`-адреса или CNAME на ту же инфраструктуру проблему надёжно не исправляет. Проверяйте доступность из реальных российских сетей.

## Вариант развёртывания: Timeweb Cloud App Platform

Официальная инструкция по Dockerfile: https://timeweb.cloud/docs/apps/deploying-with-dockerfile

1. Войди в https://timeweb.cloud/ и открой **App Platform → Создать**.
2. Подключи свой GitHub и выбери репозиторий **semen89852698936-create/granitsy-semen-chayka-**, ветку **main**. Если репозиторий приватный, разреши Timeweb доступ именно к этому репозиторию.
3. В способе сборки выбери **Dockerfile** из корня проекта. Уже добавлен готовый `Dockerfile` с Flask, Gunicorn, Python 3.11 и `EXPOSE 8080`.
4. Выбери сервер в **России** (конкретный регион из реально доступных в панели), коммерческий тариф с подходящими ресурсами и безопасную обработку секретов.
5. В дополнительных настройках укажи путь проверки состояния **/healthz**. Он возвращает 200 OK без обращения к ИИ.
6. Перед стартом выбери переменные окружения из таблицы ниже. Секретные значения вводятся только в Timeweb, не в GitHub или чат.
7. Запусти деплой. Timeweb предоставит технический домен с HTTPS; скопируй его. После проверки можно привязать короткий собственный домен .ru, например поддомен уже принадлежащего тебе сайта, если ты управляешь его DNS.

## Переменные для ПЕРВОГО технического теста

| Имя | Значение |
|---|---|
| `AI_PROVIDER` | `yandex` |
| `YANDEX_MODEL` | `aliceai-llm-flash` |
| `YANDEX_FOLDER_ID` | Идентификатор каталога Yandex Cloud |
| `YANDEX_API_KEY` | Ключ Yandex AI Studio, введённый в защищённое поле |
| `PAYWALL_ENABLED` | `0` до готовности Prodamus/базы/почты |
| `COURSE_COOKIE_SECRET` | Отдельный длинный случайный ключ, не менее 32 символов |
| `COURSE_PUBLIC_URL` | HTTPS-адрес, выданный Timeweb после деплоя |
| `PORT` | `8080` (уже задан внутри Dockerfile) |

Yandex AI Studio требует ключ с разрешением `yc.ai.foundationModels.execute` и каталог сервисного аккаунта. Официальный API: https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/completions-structured

При выборе `AI_PROVIDER=yandex` даже при наличии старого `GEMINI_API_KEY` будет использоваться Yandex AI Studio. Никакие ключи не передаются браузеру. Название модели можно заменить на другую поддерживаемую структурированным выводом модель после проверки её качества.

## Контрольный тест в России

- [ ] Открой технический HTTPS-адрес Timeweb на мобильном интернете **без VPN**.
- [ ] Повтори с другого оператора или проводного интернета; проверь загрузку всей страницы, а не только заголовка.
- [ ] `/healthz` возвращает `{"ok":true}`.
- [ ] `/api/status` возвращает `provider: yandex`, `daily_limit: 18` и доступный лимит.
- [ ] Пройди три настоящих раунда. Проверь, что ответы реалистичны по-русски, приходят за приемлемое время, оценки и итоговый разбор отображаются.
- [ ] Проверь работу на телефоне, отсутствие ошибок HTTP 403/429 и перезагрузку страницы.
- [ ] При платном запуске отдельно проверь работу Prodamus, PostgreSQL, вход по коду на почту и сценарий возврата.

**Не обещай людям доступность без VPN до проверки из российских сетей.** Проверка из Европы или из внутренней сети хостинга недостаточна.

## Платёжный режим Prodamus (после технического запуска)

После тестирования на новом домене подключи все необходимые переменные из `PAID_LAUNCH.md`: `DATABASE_URL` постоянной PostgreSQL, `PAID_ACCESS_SECRET`, `PRODAMUS_FORM_URL`, `PRODAMUS_SECRET`, `PRODAMUS_SYS`, рабочую почту (SMTP или Resend), оферту, политику и поддержку.

Затем укажи в Prodamus новый URL уведомлений **https://НОВЫЙ-ДОМЕН/api/prodamus/webhook**. Обязательно обнови `COURSE_PUBLIC_URL` на новый домен и повторно проверь подпись уведомления и сумму 399 ₽. Только потом ставь `PAYWALL_ENABLED=1`.

Учёт оплаченного доступа, остатка 90 ответов ИИ и дневного лимита работает через PostgreSQL и не связан с Vercel. Старые адреса можно временно сохранить для демонстрации, но не использовать в рекламе для России.

## Что важно по расходам и безопасности

- На Timeweb потребуется выбрать и оплатить план App Platform; цена зависит от конфигурации и региона.
- Yandex AI Studio тарифицирует обработанные токены, а не само наличие тренажёра. Контролируй бюджет и лимиты в Yandex Cloud.
- Для сайта самозанятого проверь публичную оферту, политику персональных данных, формирование чеков и условия Prodamus.
- На российском хостинге Vercel Firewall больше не защищает `/api/chat`. Существующие серверные ограничения (лимит по аккаунту при оплате, анти-спам и локальные лимиты по IP) сохраняются, но перед массовым запуском нужен отдельный сетевой rate limit на новой площадке.
- Никогда не размещай ключи Яндекса, Prodamus, пароли БД и секреты электронной почты в GitHub или публичном HTML.

## Проверка контейнера в GitHub

Workflow `.github/workflows/russia-container-smoke.yml` собирает Docker-образ и проверяет `/healthz`, главную страницу и выбор провайдера Yandex с фиктивными ключами. Он **не совершает реальные запросы** к платному API. Тест настоящего Gemini и настоящего Yandex проводится отдельно с разрешёнными провайдерами.
