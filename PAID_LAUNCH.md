# Платный курс «Личные границы» - запуск через Prodamus

**На сегодня платный режим не активирован.** Изменения уже внесены, но PAYWALL_ENABLED по умолчанию отключён, чтобы не закрывать действующий бесплатный курс до готовности сервиса.

**Для покупателей в России:** прежние адреса `*.vercel.app` могут не открываться без VPN. Перед продажами **разверни приложение на российском хостинге** по инструкции [DEPLOY_RUSSIA.md](DEPLOY_RUSSIA.md) и убедись, что пользователи из РФ открывают его без VPN. Для российского сервера рекомендуется `AI_PROVIDER=yandex` c Yandex AI Studio, а `COURSE_PUBLIC_URL` и URL webhook в Prodamus должны указывать на проверенный новый адрес. Все настройки Vercel ниже относятся только к старому хостингу.

## Что реализовано

- Разовая покупка 399 ₽. Бессрочный доступ к материалам и упражнениям, 90 ответов ИИ (30 полных 3-раундовых диалогов) без срока сгорания; 18 ответов ИИ (6 диалогов) в сутки.
- Платёжная ссылка с уникальным номером заказа и подписью HMAC SHA-256; callback POST /api/prodamus/webhook проверяет подпись, статус success, сумму 399.00, email, домен и sys. Повторы не продлевают доступ повторно.
- Вход по разовому 8-значному коду из письма (действует 10 минут, 5 попыток), максимум две активные сессии; повторный вход после истечения сессии не требует оплаты.
- Оплаченный статус и остаток кредитов хранятся в PostgreSQL, а не в cookie. Неоплаченный посетитель не получает полный HTML курса или доступ к /api/chat.
- Автоматическое возвращение списанных кредитов при ошибке ИИ и отдельный учёт попыток входа и оформления заказа в базе.
- Платная страница выдержана в стиле существующего сайта; старый тренажёр без изменений при PAYWALL_ENABLED=0.

## 1. Что подготовить в Prodamus

Адрес платежной формы (пример https://merchant.payform.ru/); секретный ключ платежной страницы (не отправлять в чат); согласованный с поддержкой Prodamus код SYS для самостоятельной интеграции. В кабинете формы укажи URL уведомлений:

https://granitsy-semen-chayka.vercel.app/api/prodamus/webhook

Рекомендуется включить «Оплата только по прямой ссылке» и настроить автоматическое формирование чеков самозанятого через «Мой налог». Возврат клиента с платёжной страницы НЕ является подтверждением оплаты. Демо-форма Prodamus может подписывать вебхуки ключом с суффиксом demo; такие уведомления нельзя принимать за реальные.

Официальная документация: https://help.prodamus.ru/payform/integracii/rest-api/instrukcii-dlya-samostoyatelnaya-integracii-servisov

## 2. Постоянная база покупателей

Нужна PostgreSQL (например Neon либо Supabase) со строкой доступа DATABASE_URL, лучше pooled connection с TLS. SQLite в памяти Vercel Functions для оплат НЕ подходит. При первом подключении SQLAlchemy создаёт таблицы course_accounts, course_orders, course_login_codes, course_sessions, course_rate_buckets. Перед запуском включи резервное копирование.

## 3. Письма с кодами

Выбери Resend (RESEND_API_KEY и MAIL_FROM) или защищённый SMTP (SMTP_HOST, SMTP_USER, SMTP_PASS, MAIL_FROM и SMTP_PORT=465 или 587). Почту нужно проверить на Яндексе, Mail.ru и Gmail. Секреты не публиковать.

## 4. Оферта и политика

Нужны утверждённые владельцем документы с реальными данными самозанятого, условиями продажи цифрового курса, бессрочным доступом к материалам, 30 ИИ-диалогами без срока сгорания, возвратами, обработкой email и передачей реплик Gemini. Публикуются по HTTPS. Код не подставляет вымышленные реквизиты.

## 5. Переменные Vercel (Production)

| Переменная | Значение |
|---|---|
| PRODAMUS_FORM_URL | Адрес личной формы https://...payform.ru/ |
| PRODAMUS_SECRET | Секрет Prodamus, sensitive |
| PRODAMUS_SYS | Согласованный с Prodamus код интеграции |
| DATABASE_URL | PostgreSQL URL, sensitive |
| PAID_ACCESS_SECRET | Случайная строка не менее 32 символов, sensitive |
| RESEND_API_KEY | Ключ Resend; либо вместо него SMTP_* |
| SMTP_HOST, SMTP_USER, SMTP_PASS, SMTP_PORT | Если используется SMTP вместо Resend |
| MAIL_FROM | Подтверждённый адрес отправителя |
| LEGAL_OFFER_URL | HTTPS URL публичной оферты |
| LEGAL_PRIVACY_URL | HTTPS URL политики |
| SUPPORT_EMAIL | Реальный адрес службы поддержки |
| COURSE_PUBLIC_URL | https://granitsy-semen-chayka.vercel.app |
| PAYWALL_ENABLED | 0 пока тестируем, затем 1 |

Не добавляй секретные ключи в GitHub или чат. Для PAID_ACCESS_SECRET можно использовать Python: secrets.token_hex(32). Не менять секрет после начала продаж, иначе коды входа и ограничения придется пересоздать.

**Важно:** коммерческое использование Vercel Hobby недопустимо. Перед платными продажами нужен тариф Pro или другой коммерческий хостинг. Gemini также имеет собственную квоту; проверь условия платного сервиса.

## 6. Контрольный чек-лист включения

1. Подключи свою форму Prodamus, PostgreSQL, почту, публичную оферту и политику конфиденциальности.
2. В тестовом окружении включи PAYWALL_ENABLED=1 и проверь: неоплативший не видит HTML тренажёра и получает HTTP 401 на /api/chat.
3. Проверь подписанный заказ 399 ₽. Переход на /payment/return без webhook не даёт доступа.
4. Убедись, что фальшивые вебхуки отклоняются, а истинный подписанный успех открывает доступ ровно один раз.
5. Введи email покупателя, получи одноразовый код, войди; проверь два устройства, выход и повторное использование кода.
6. Проведи 3 раунда Gemini: суточный остаток 18 → 17 → 16 → 15, общий 90 → 89 → 88 → 87.
7. Проверь email-рассылку, реальные чеки «Мой налог», политику возвратов, мобильную версию и список отказов Gemini.
8. Только после успешного теста и перевода хостинга на коммерческий тариф активируй PAYWALL_ENABLED=1 в Production.

### Дополнительные замечания

- Два устройства допускаются, но реплики и локальный прогресс сохраняются в браузере, пока не введена синхронизация между устройствами.
- При возврате оплаты требуется отозвать право доступа в базе; в текущей версии автоматическая обработка возврата не предусмотрена.
- Дневные лимиты оплаченного аккаунта не зависят от очистки cookie. Прямое распространение ссылки не даёт доступа, но полностью исключить передачу одноразового кода самим покупателем нельзя.
