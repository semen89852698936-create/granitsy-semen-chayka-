# Запуск курса «Интерактивный курс по личным границам от Семёна Чайки»

## Что в комплекте
- `index.html`: интерфейс курса на 30 ситуаций и упражнения.
- `ai_server.py`: сервер с ИИ-собеседником; API-ключ не передаётся в браузер.
- `scenarios.json`: база учебных ситуаций.
- `render.yaml`: конфигурация для бесплатного Web Service на Render.
- `.gitignore`: исключает локальный ключ из Git.

## Шаги без собственного сайта
1. Распакуй ZIP на компьютере.
2. Зарегистрируйся на https://github.com/ и создай **приватный** репозиторий, например `granitsy-course`. Загрузи **содержимое папки** курса в корень репозитория (файл `render.yaml` должен лежать в корне). Не загружай реальный `.env` или API-ключ.
3. Зарегистрируйся на https://render.com/ и подключи свой GitHub-аккаунт.
4. Render Dashboard -> New -> Blueprint. Выбери репозиторий с `render.yaml` и запусти создание ресурса.
5. В запросе значения `OPENAI_API_KEY` вставь API-ключ, выпущенный на https://platform.openai.com/api-keys. Вставляй его **только в секретное поле Render**. Никому не пересылай и не вставляй в HTML.
6. Убедись, что выбран **Free** план для Web Service (он указан в конфигурации). Дождись статуса Live.
7. Открой выданный адрес `https://имя-сервиса.onrender.com` с телефона. Зайди в режим «ИИ-собеседник» и проверь три раунда разговора.
8. Скопируй ссылку в Telegram, Instagram или на страницу с описанием курса.

## Настройка бюджета
- В OpenAI API Console создай отдельный проект для курса. В Project -> Limits выставь ежемесячный лимит (например, $5) и включи **Enforce a hard limit**. Добавь оповещения. Применение лимита не мгновенное: затраты могут немного превысить заданное значение.
- В `render.yaml` лимит `RATE_LIMIT_PER_10_MIN` равен 15 запросам за 10 минут с одного IP (то есть около 5 полных 3-раундовых тренировок). Это базовая защита, **не гарантия** от злоупотреблений: лимиты сбрасываются при перезапуске сервиса, а пользователи могут менять IP. Для публичного массового запуска добавь CAPTCHA/проверку пользователя, квоты и мониторинг.
- Пользователям не нужно покупать ChatGPT. OpenAI API оплачивается отдельно владельцем проекта.

## Важные ограничения
- Бесплатный Render усыпляет веб-сервис после 15 минут без запросов; первый запрос может запускать его около минуты. Для большой аудитории, высоких требований к доступности и чувствительных данных бесплатный тариф не подходит.
- Результаты тренировки хранятся в браузере ученика и могут исчезнуть при очистке данных. Синхронизации устройств и учётных записей нет.
- Реплики учеников уходят на твой сервер и в OpenAI API. Не проси учеников сообщать личные или чувствительные сведения. Перед публичным запуском добавь краткую политику конфиденциальности и уведомление об использовании ИИ.
- Проверка интеграции в этом пакете проводилась без живого API-ключа. Полноценную работу с моделью необходимо проверить после подключения API и оплаты.

## Альтернативный ручной деплой
Если Blueprint недоступен, в Render: New -> Web Service, выбрать репозиторий, Python, Free, `buildCommand`: `python -m compileall -q ai_server.py`, `startCommand`: `python ai_server.py`. Добавить переменные `HOST=0.0.0.0`, `OPENAI_MODEL=gpt-6-luna`, `OPENAI_API_KEY` (secret). Порт Render передаёт автоматически через `PORT`.
